Installation steps (Android)

  1. Download the APK with your browser (Chrome recommended).
  2. When Chrome asks to install, tap OK / Install. If blocked, follow step 3.
  3. Go to Settings → Apps → Chrome → Advanced → Install unknown apps (or "Special app access") and allow Allow from this source.
  4. Return to the download, tap the APK, then Install.
  5. Open RideKSA and sign in with Google or email.

If Play Protect shows a warning, tap More details → Install anyway. The app is signed by GalaxyLabs (RideKSA).
